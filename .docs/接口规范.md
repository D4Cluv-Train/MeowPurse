# 喵记 (MeowPurse) 接口规范

---

## 1. 基础地址

```
meowpurge/api
```

## 2. 统一返回格式

```json
{
    "code": 200,
    "data": {},
    "message": "ok"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | HTTP 状态码，200=成功 |
| `data` | object/array | 响应数据（失败时为 null） |
| `message` | string | 提示信息（成功时为 "ok"） |

## 3. 请求方式

| 操作 | HTTP 方法 | 说明 |
|------|-----------|------|
| 查询 | GET | Query 参数传参 |
| 创建 | POST | JSON body |
| 更新 | PUT | JSON body，全量替换 |
| 删除 | DELETE | 无请求体 |

## 4. 认证方式

JWT Bearer Token：

```
Authorization: Bearer <token>
```

## 5. 路由命名规范

- 路径全部小写，按模块划分
- **资源用名词复数**，HTTP 方法表达操作：

| 操作 | HTTP | 路径示例 |
|------|------|----------|
| 查询列表 | GET | `/bills` |
| 查询单个 | GET | `/bills/{id}` |
| 创建 | POST | `/bills` |
| 更新 | PUT | `/bills/{id}` |
| 删除 | DELETE | `/bills/{id}` |

- **非 CRUD 操作**（登录、语音识别等）使用统一动词路径：
  - `POST /auth/login` — 登录
  - `POST /voice/recognize` — 语音识别

## 6. 通用响应状态码

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 / Token 无效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 资源冲突 |
| 500 | 服务器内部错误 |

## 7. 分页列表

**请求参数**（Query）：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `page` | int | 1 | 页码 |
| `page_size` | int | 20 | 每页条数（最大 100） |

**响应格式**：

```json
{
    "code": 200,
    "data": {
        "items": [],
        "total": 0,
        "page": 1,
        "page_size": 20
    },
    "message": "ok"
}
```
