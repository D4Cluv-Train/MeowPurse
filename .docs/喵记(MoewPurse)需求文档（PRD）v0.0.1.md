# 语音记账Agent产品需求文档（PRD）v0.0.1

## 1. 产品概述
- **产品名称**：喵记（MeowPurse）
- **产品定位**：一款基于AI Agent的轻量化语音记账工具，通过“语音输入+自动结构化+智能复盘”闭环，解决个人用户“记账难坚持、数据难复盘”的核心痛点。
- **核心价值**：将单笔记账时间压缩至3秒内，通过AI自动生成周/月/年消费洞察，让用户从“记录者”变为“财务管理者”。
- **目标用户**：20-35岁有记账意愿但难以坚持的年轻职场人、学生群体。
- **MVP目标**：验证“语音记账”核心链路的可用性与用户接受度，跑通“输入-处理-反馈”最小闭环。

## 2. 核心功能架构（v0.0.1）
- **语音记账模块**
  - 支持普通话语音输入，自动提取金额、时间、消费类别、备注。
  - 提供置信度排序的备选项，支持一键切换或语音+文本混合编辑。
  - 强制“人在回路”确认机制，用户确认后方可保存账单。
- **数据管理模块**
  - 账单的增删改查、分类管理、云端同步。
  - 支持按时间、类别、金额筛选账单。
- **智能复盘模块**
  - 生成周/月消费概览、趋势图、分类占比。
  - 提供1-2条AI消费建议（基于预设Prompt模板）。
  - 支持复盘报告导出为图片或文本。

## 3. 技术架构概览
- **前端**：React Native + TypeScript，实现跨平台语音输入、账单确认、复盘展示页面。
- **后端**：FastAPI，提供RESTful API，处理语音识别、Agent编排、数据存储请求。
- **Agent编排**：LangGraph，定义“录音→识别→解析→确认→保存”状态机，支持流程暂停与人工复核。
- **数据存储**：MySQL存储结构化账单数据，Redis缓存用户会话与高频账单，Milvus预留向量检索能力（v0.0.1暂不启用）。
- **AI模型**：DashScope免费模型（SenseVoice语音识别、Qwen-Turbo信息抽取与复盘生成）。

## 4. 非功能需求
- **性能**：语音识别响应时间≤2秒，账单保存响应时间≤1秒。
- **安全**：数据传输与存储全程加密，支持用户随时导出/删除数据。
- **兼容性**：支持iOS 14+、Android 10+主流机型。

## 5. 版本规划
- **v0.0.1（MVP）**：完成语音记账核心链路，验证用户接受度与AI解析准确率。
- **v0.1.0**：优化语音识别鲁棒性，增加方言支持，完善复盘建议质量。
- **v0.2.0**：接入Milvus，实现基于消费习惯的语义搜索与个性化推荐。
- **v1.0.0**：支持多用户协作记账、家庭账本、消费目标管理等进阶功能。

## 6. 风险与应对
- **语音识别准确率不足**：MVP阶段聚焦安静环境与标准普通话，提供备选项与混合编辑降低纠错成本。
- **AI幻觉导致账目错误**：强制“人在回路”确认机制，建立用户纠错反馈闭环。
- **用户隐私担忧**：端到端加密，本地化处理语音特征，透明展示隐私政策。

## 7. 后续迭代方向
- 增加多模态输入（图片识别小票、截图导入账单）。
- 接入银行/支付平台API，实现自动对账。
- 增加消费目标设定与达成提醒功能。
- 支持多用户协作记账与家庭账本。

## 💡 PRD使用建议
- 本PRD为v0.0.1版本，聚焦MVP核心链路，后续迭代需根据用户反馈与数据表现动态调整。
- 开发过程中需严格遵循“轻量化”原则，避免功能冗余，确保每个版本都能交付可用价值。
- 建议每周同步一次开发进度与用户反馈，及时调整产品方向与技术实现。
